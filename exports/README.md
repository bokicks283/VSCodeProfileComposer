# Profile exports

After a manually maintained VS Code profile is stable:

1. Export it from VS Code as a `.code-profile` file.
2. Review the export for personal paths, credentials, tokens, private connection data, account state, and machine-only values.
3. Store safe backups privately.

`.code-profile` files are ignored here by default. This public repository documents profile design; it is not the storage location for sensitive runtime exports.
